## Release evidence

- The public website and website import shipped in [962778d](https://github.com/Rishi-creator-11/callpilot/commit/962778df538c3a6cad72d5aa5c33bd9cdee51c67). Render reported the commit live. Live checks returned HTTP 200 for homepage, pricing, app and health, and HTTP 401 for unauthenticated import.
- Supabase confirmed the website source index is unique per workspace and that row-level security is enabled on the document table.
- The Google redirect fix was made in the Google client configuration. Google accepted the redirect and displayed account selection. No successful CallPilot OAuth callback or workspace creation was observed in this session.
- No Goodcall or CallPilot paid plan, production phone transfer, customer integration, real booking, or real order was executed during verification.
