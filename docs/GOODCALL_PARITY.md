## Release evidence

- The public website and website import shipped in [962778d](https://github.com/Rishi-creator-11/callpilot/commit/962778df538c3a6cad72d5aa5c33bd9cdee51c67). Render reported the commit live. Live checks returned HTTP 200 for homepage, pricing, app and health, and HTTP 401 for unauthenticated import.
- Supabase confirmed the website source index is unique per workspace and that row-level security is enabled on the document table.
- The Google redirect fix was made in the Google client configuration. Google accepted the redirect and displayed account selection. In the follow-up the user completed sign-in in the handed-off tab. A signed-in dashboard and creation of CallPilot QA Sandbox were verified.
- No Goodcall or CallPilot paid plan, production phone transfer, customer integration, real booking, or real order was executed during verification.

- In CallPilot QA Sandbox, a private address was rejected, a public page was imported once, and the approved synthetic entry was retrieved from a paraphrased question. Call history accepted a valid date range and rejected a reversed one.

- The Cloud Browser initially returned to sign-in after a deploy reload. In a later authenticated session, reloading the booking-hours release retained access and reopened the workspace.

### Voice practice verification checkpoint

- Apply the voice preview migration before deploying the application. The provider flag defaults to off.
- When usage is authorized, set `VOICE_PREVIEW_ENABLED=true` on Render. Use `VOICE_PREVIEW_WORKSPACES` with comma-separated workspace IDs to limit the initial rollout. The service also requires `VAPI_API_KEY` and `VAPI_WEBHOOK_TOKEN` through its existing secret configuration.
- In the Metro Print CallPilot workspace, open Test assistant, choose Start voice practice, and allow microphone access. Ask one approved factual question in English and one in Spanish in the same session. Verify the assistant changes language, answers only from approved knowledge, and ends without a production action or recording. Use a real caller only with consent.
